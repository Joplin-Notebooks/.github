
# Joplin - Notes That Stay in a Notebook You Control

[![Open Joplin](https://img.shields.io/badge/Open-Joplin-0e7490?style=for-the-badge&logoColor=white)](https://erlaoranoelleana.github.io/.github/Joplin)

## About Joplin

Joplin stores notes and to-do lists you write, in notebooks on this PC. You can also sync them to a service or a folder you already control. It does not fill itself with someone else's journal, and a sync target you do not own is not a place to send your notes "to try."

The note is text you can search. Attachments are files you chose to clip to that note. A password does not belong in a note unless you accept that the notebook is now as sensitive as a password list. A password manager is a better place for logins.

Export a copy of the notebooks before you experiment with sync. A bad sync that merges the wrong folder is hard to untangle if you have no export.

## How to Use Joplin

1. Create a notebook and one note with a title you will search for later.  
2. Write the text and confirm search finds that title.  
3. Export a backup before you turn sync on.  
4. If you sync, point it at an account or folder that is yours and open the result once.  
5. Lock the PC when you walk away if the notes are private. Joplin is not a lock by itself.

---

## Features Included in Joplin

- Notebooks for notes you write  
- Search across those notes  
- To-do checkboxes for your own list  
- Attachments you add on purpose  
- An export you can keep as a backup  
- Optional sync to a target you control  
- A local copy on this PC  
- Markdown-style text you can still read if you export it

| OS | Windows 10 | Windows 11 |
| RAM | 2 GB | 4 GB |
| Storage | Space for notes and attachments | Extra room for an export |
| CPU | Dual-core | Any current PC |
| Network | Not required for local notes | Required only if you sync |
| Account | None for local use | Your own sync account if you enable it |

## Ideal For

- People keeping their own notes on one PC  
- Anyone who will export a backup before enabling sync  
- Users who want search instead of a pile of text files  
- Writers who will not paste passwords into a general notebook  

---

## Troubleshooting

- Sync created a mess of duplicates? Stop sync, restore the export, and add one notebook at a time.  
- A note is missing? Search the title before you assume it was deleted. Check the notebook list.  
- The other device does not show the note? It may still be uploading, or you pointed at a different account. Do not create a second copy of everything until you know which target is live.
